Possible combinations

Each chassis type against each hub you own, counting only parts from that hub's connector family. Layouts counts the distinct ways to place the parts in the ports.

Simulate

A top-down rehearsal of the current build: same ports, same wheel size, same sensors. Use it to tune values before the robot is in your hands, not as a promise of how the real one behaves.

Rule table

Checked top to bottom on every tick; the first rule that matches drives the motors. Hold keeps a rule running for that many milliseconds once it fires. Speeds are percent of top speed.

Goal and decider

Every half second, code turns the sensor numbers into plain facts and asks which mode fits the goal. In the browser a local stand-in answers, because a TypeSafe key must never sit in a web page. The request shown beside the arena is what the bridge sends to Jev.

Below this confidence the robot keeps its current mode instead of switching. Low values flip-flop, high values commit late.

Projects

Eighteen projects in five levels, from one spinning motor to a robot that asks Jev what to do next. Each one is marked against your kits; the ones with a simulator setup load straight into the arena.

Models and ideas

Builds other people have published with instructions, so you can replicate them instead of starting from a pile of beams, and ideas that go past the box. Each model names its kit, its programming path, and what you would need beyond the box. Links go to the source; nothing is copied here.

Paths and hardware

How to program each hub today, what to buy for each path, and where an AI decision layer fits without getting in the way of the motors.

Export code

The current build and brain as Pybricks MicroPython. Rules export as a loop on the hub. Modes export as a hub program that reports facts, plus a laptop bridge that asks Jev and sends back a mode.

Link to the hub

Connect to a Robot Inventor Hub running Pybricks from this page, over Bluetooth LE. Watch what it senses, switch its mode, drive it by hand, or let the stand-in decider pick. Try it on the virtual hub first: that is the simulator answering exactly as the exported program would.
